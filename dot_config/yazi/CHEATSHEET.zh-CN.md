# Yazi 速查表

这份表专门针对你现在这台机子的最小配置，不追求列全，只覆盖最常用动作。

## 启动

- 推荐启动：`y`
- 也可以直接：`yazi`

说明：
你现在 shell 里的 `y` 不是原生命令，而是我加的包装函数。
它的作用是：退出 Yazi 后，shell 会自动切到你最后停留的目录。

## 最核心的导航

- 上移：`k`
- 下移：`j`
- 进入目录：`l` 或 `Enter`
- 返回上级目录：`h`
- 回到上一个目录历史：`H`
- 前进到下一个目录历史：`L`

## 选择与复制移动

- 选中/取消当前文件：`Space`
- 进入可视选择：`v`
- 复制（yank）：`y`
- 剪切：`x`
- 粘贴：`p`
- 删除到回收站/垃圾桶：`d`
- 永久删除：`D`

## 创建与重命名

- 新建文件/目录：`a`
- 重命名：`r`
- 批量重命名：选多个后 `r`

## 搜索与过滤

- 当前目录内查找文件名：`f`
- 全文搜索：`s`
- 过滤当前列表：`/`

说明：
不同版本里搜索入口的语义会稍有差异，但你先把“找文件名”和“搜内容”这两个概念分开记就够了。

## 预览与信息

- 打开文件信息/spot：`Tab`
- 关闭信息面板：`Esc` 或 `q`
- 预览窗口滚动：`J` / `K` 或 `PageDown` / `PageUp`

## 打开文件

- 默认打开：`Enter`
- 交互式选择打开方式：`o e`

说明：
你这里配了文本类文件优先走 `$EDITOR`，也就是 `nvim`。
所以很多代码/配置文件直接回车就会进 `nvim`。

## 这台机子额外加的快捷键

- `g .`
  - 切换隐藏文件显示
- `g h`
  - 回到 Home 目录
- `g c`
  - 进入 `~/.config`
- `g f`
  - 用 `fd` 打开三层平铺视图，适合快速扫项目结构
- `g r`
  - 用 `rg` 做全文搜索
- `o e`
  - 交互式选择 opener

## 隐藏文件与配置目录

你大概率会经常操作这些：

- `.env`
- `.gitignore`
- `.config/`
- 项目里的隐藏目录

所以最常用的组合通常是：

1. `g .`
2. `g c`
3. `Enter` 进某个配置目录

## 和 shell 联动的正确用法

如果你只是想浏览：

```bash
y
```

如果你想从当前项目开始：

```bash
y .
```

如果你想进某个目录并在退出后把 shell 留在那：

```bash
y ~/project
```

## 推荐上手动作

1. `y`
2. 用 `j/k` 移动
3. `Enter` 进目录
4. `h` 返回
5. `g .` 看隐藏文件
6. `g c` 跳到配置目录
7. 找一个 `toml` 或 `lua` 文件按 `Enter`
8. 从 `nvim` 退出后再从 `yazi` 退出

这样你能马上理解：

- 文件浏览
- 编辑器联动
- 退出后 shell 跟随目录

## 你现在最值得先记住的 8 个键

- `j` / `k`：上下移动
- `h` / `l`：返回 / 进入
- `Enter`：打开
- `Space`：选中
- `y`：复制
- `x`：剪切
- `p`：粘贴
- `g .`：切换隐藏文件

## 什么时候该用 Yazi，什么时候别用

适合用 Yazi：

- 浏览项目目录
- 做批量复制/移动/重命名
- 找配置文件
- 预览 JSON / Markdown / 图片 / PDF / 压缩包

不适合硬用 Yazi：

- 特别复杂的代码搜索替换
- Git 提交历史查看
- 大量文本编辑

这些场景一般还是交给：

- `nvim`
- `rg`
- `lazygit`
